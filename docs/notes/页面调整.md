# 页面调整

本文记录博客文章详情页的排版与右侧 TOC（目录）调整方式。样式只作用于文章详情页，不影响首页、文章列表和其他普通页面。

## 文章详情页排版

### 生效范围

`src/components/views/RenderPost.astro` 向 `StandardLayout` 传入 `isArticle`。

`src/layouts/StandardLayout.astro` 据此给文章页添加两个类：

- 头部：`post-header`
- 正文：`post-content`

因此，文章详情页专属样式统一写在 `src/styles/prose.css` 的 `.prose.post-content` 下；不要直接修改全局 `.prose`，否则会影响首页及其他页面。

### 正文字体与宽度

当前规则位于 `src/styles/prose.css`：

```css
.prose.post-content {
  font-size: 1rem;
  line-height: 1.65;
}
```

- 正文为 `16px`；通过 `line-height` 调整同一段多行文字的行距。
- 段落、列表的上下间距为 `0.5em`（8px）。
- 相邻列表项的间距为 `0.2em`（3.2px）。嵌套列表的上下间距也使用该值，避免第一项与后续项的间距不一致。
- 大屏（`min-width: 1280px`）下，文章头部和正文从默认 `65ch` 加宽到 `70ch`。右侧 TOC 仍固定显示，并保留安全间隔；小屏保持原宽度。

如需调节阅读密度，优先修改 `.prose.post-content` 的 `line-height`，再修改段落／列表的 `margin`，不要只改列表项间距。

### 标题样式与间距

文章页标题规则同样位于 `src/styles/prose.css`：

| 层级 | 当前字号 | 字重 | 颜色 | 上下间距 |
| --- | --- | --- | --- | --- |
| H2 | `1.6em`（25.6px） | 800 | `var(--fg-deep)` | `1.1rem`（17.6px） |
| H3 | `1.1875em`（19px） | 700 | `var(--fg-deep)` | `0.8rem`（12.8px） |
| H4–H6 | `1em`（16px） | 继承各级默认字重 | `var(--fg)`（浅色主题为深灰） | `0.65rem`（10.4px） |

同一级标题的上、下间距保持相同；H2、H3、H4–H6 逐级缩小，以便内容结构清晰但不显得松散。

### 文章头部

- 全站页面标题基础样式在 `src/styles/main.css` 的 `.prose h1.page-title`。
- 文章详情页通过 `.prose.post-header h1.page-title` 覆盖为 `2.5rem`，不影响其他页面标题。
- `StandardLayout.astro` 中，普通页面头部下边距为 `3.5rem`，文章页为 `1.75rem`。
- 副标题和文章元信息的负边距分别由 `StandardLayout.astro` 与 `src/components/base/PostMeta.astro` 控制；有副标题时使用较小的负边距，避免标题、副标题、日期和标签挤在一起。

## 右侧 TOC

### 开关与层级范围

在 `src/config.ts` 的 `FEATURES.toc` 中配置：

```ts
toc: [
  true,
  {
    minHeadingLevel: 2,
    maxHeadingLevel: 4,
    displayPosition: 'right',
    displayMode: 'content',
  },
]
```

- `minHeadingLevel`、`maxHeadingLevel`：目录包含的标题层级。
- `displayPosition`：`right` 或 `left`。
- `displayMode`：`always` 始终显示、`hover` 悬停显示、`content` 悬停文章内容时显示。

### TOC 尺寸与位置

`src/components/base/DesktopAside.astro` 控制桌面目录容器：

- `--desktop-toc-width: 12rem`：目录宽度。
- `top: 8.875rem`：距顶部位置。
- 右侧目录通过 `left: calc(100vw - var(--desktop-toc-width) - 3.2rem)` 固定在视口右侧。
- 屏幕小于 `1200px` 时隐藏桌面 TOC，改用文章内的移动端目录控件。

`src/components/toc/TocSidebar.astro` 控制目录列表：

- 最大高度为 `74vh`，超出后独立滚动。
- 字号为 `calc(var(--blog-reading-size) * 0.9)`。

`src/styles/main.css` 中的 `#toc-sidebar` 规则控制条目缩进、行高、省略号和激活态透明度。

## 验证

修改后运行本地预览：

```bash
pnpm dev
```

至少检查以下内容：

1. 文章正文的多行行距、段落间距和嵌套列表间距是否一致。
2. H2–H6 的字号、颜色及上下间距是否符合层级。
3. 宽屏下正文加宽后，右侧 TOC 与正文之间仍有空隙；窄屏下桌面 TOC 是否隐藏。
