# 2026-08-09 页面更新说明

本次更新集中在首页、Blogs、Projects 和 Friends 的内容与布局，同时调整 OG 图片生成开关与示例内容。

## 首页

- 新增 `HomeHeader.astro` 和 `TinyDesktop.astro`。
- 标题区改为“文字 + 纯 CSS 复古桌面”布局，移动端改为纵向排列。
- 副标题更新为 `INTJ ｜ Unwavering to the end`。
- 首页正文合并为 Stack 介绍，新增 GitHub 概览与语言统计，并调整社交区文案。

## Blogs 与示例内容

- Blogs 列表页副标题更新为 `Record my Trajectory`。
- Markdown 指南的示例图片改用 `/vue.png`，不再依赖 OG fallback 图片作为文章配图。

## Projects

- 副标题更新为 `Currently Working on`。
- 大号描边分类标题改为紧凑的小型标签。
- 卡片网格最小列宽改为 `240px`，缩小卡片、组内和组间留白；移动端使用单列。
- 补充 Trajex、skills、pi-extensions、PageIndexRag-Web 和 RepoMirror 等项目。
- `icon` schema 改为可选，当前项目数据不再指定图标；UnoCSS safelist 同步兼容缺省图标。

### 开发模式的内容同步

修改 Astro Content Collection schema 后，旧的开发进程可能暂时使用旧内容存储，表现为 Projects 页显示 `No content available for display`。重启 `pnpm dev` 会触发 `Clearing content store` 和内容重新同步。

## Friends

- 友链主容器和申请面板改为透明背景，减少重复色块。
- `FriendsApplyPanel.astro` 移除 `copy` / `hint` props，改为固定的联系邮箱与参考格式。
- 参考格式包含站点名称、站点链接、头像链接和站点描述；桌面端双栏，移动端单栏。

## OG 图片

- `FEATURES.ogImage` 全局开关设为 `false`，暂停新的自动 OG 图生成。
- OG 生成代码、页面 frontmatter 和 `public/og-images/` 中的静态图片仍然保留，日后可通过恢复 `FEATURES.ogImage` 配置重新启用。

## 验证

发布前需要执行：

```bash
pnpm check
pnpm build
```

同时检查 `/`、`/blogs/`、`/projects/` 和 `/friends/` 的桌面端与移动端布局。
