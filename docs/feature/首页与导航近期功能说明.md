# 首页与导航近期功能说明

本文档以当前代码为准，说明 PR #21 之后合并的三项用户可见功能：首页 Blog 统计、首页近期笔墨、导航时间进度。对应合并提交：

- [PR #49](https://github.com/wutongyuonce/YuBlog/pull/49) `901b95e`：首页 Blog 统计
- [PR #52](https://github.com/wutongyuonce/YuBlog/pull/52) `a50daf5`：导航时间进度
- [PR #54](https://github.com/wutongyuonce/YuBlog/pull/54) `7ba8ead`：首页近期笔墨

## 1. 首页 Blog 统计

副标题下方有一行等宽数字统计，格式为 `N篇 · N字 · N天`。

数据来自已发布 Blog，不读草稿：

```text
src/content/blogs/**/*.md(x)
        ↓
getPublishedBlogPosts()          始终排除 draft
        ↓
render(post)                     读取 remarkPluginFrontmatter.wordCount
        ↓
getBlogStats()
        ↓
HomeHeader.astro
  篇数：postCount
  字数：formatChineseCount(wordCount)
  天数：daySpan
```

计算规则：

1. `wordCount` 由 `plugins/remark-reading-time.ts` 在渲染时写入。它用 `countReadableUnits()` 统计纯文本：每个 CJK 字符算 1，其余按单词计。
2. `getBlogStats()` 对每篇文章调用 `render()` 再求和。任一文章缺少 `wordCount` 时直接抛错，不会把缺值当成 0。
3. `daySpan` 取最早、最晚 `pubDate` 的 UTC 日历日差。文章少于 2 篇时为 `0`。
4. 字数小于 `10000` 时按 `zh-CN` 原样显示；达到万级后改写为 `1.2万` 这种形式，超过 `100` 万时不再保留小数。
5. 阅读时长仍按 `200` 可读单位/分钟估算，且至少 1 分钟；文章手动写了 `minutesRead` 时不覆盖。

首页统计和博客列表的草稿策略不同：列表在开发环境会显示草稿，首页统计始终排除草稿。

## 2. 首页近期笔墨

个人介绍下方渲染 `RecentWriting`。没有已发布文章时整块不输出。

用户可见行为：

- 标题为 `RECENT WRITING` / `近期笔墨`。
- 最多 5 篇，按 `pubDate` 倒序。
- 每项包含序号、标题链接、最多 2 个标签、日期。
- 日期按 `Asia/Shanghai` 日历日计算：当天为 `今天`，1–30 天前为 `N天前`，更早或未来日期输出完整中文日期加星期。
- 构建时写入初始文案；浏览器在首次执行和 `astro:page-load` 后再按访问时刻刷新相对日期。
- 链接过渡只在 `prefers-reduced-motion: no-preference` 时启用。

数据链路：

```text
getPublishedBlogPosts()
        ↓
getSortedPosts()
        ↓
getRecentBlogPosts()             slice(0, 5)
        ↓
RecentWriting.astro
        ↓
formatRecentPostDate()           服务端初值 + 客户端刷新
```

## 3. 导航时间进度

`NavBar` 在 Logo 右侧挂载 `ProgressStats`，三项为：

| 显示 | 含义 |
| :-- | :-- |
| 今年第几天 | 本地时区下的年积日，1 月 1 日为 1 |
| 年度进度 | 从当年 0 点到下一年 0 点的已过比例，四舍五入为整数百分比 |
| 今日进度 | 从当天 0 点到次日 0 点的已过比例，四舍五入为整数百分比 |

行为细节：

- 首屏 HTML 是 `--`，脚本执行后写入真实数字。
- 使用访问者本地时区，不使用站点 `Asia/Shanghai`。
- `astro:page-load` 时刷新一次；全页只启动一个 `30s` 定时器，用 `document.documentElement.dataset.progressClock` 防止 ClientRouter 重复创建。
- 窄屏缩小字号和间距，不改三项含义。

```text
NavBar.astro
        ↓
ProgressStats.astro
        ↓
getProgressStats(new Date())
```

## 4. 文件职责

| 文件 | 职责 |
| :-- | :-- |
| `src/pages/index.mdx` | 首页入口；`head` 挂 `HomeHeader`，正文后挂 `RecentWriting` |
| `src/components/home/HomeHeader.astro` | 标题、副标题、Blog 统计与复古桌面 |
| `src/components/home/RecentWriting.astro` | 最近 5 篇时间线与相对日期刷新 |
| `src/components/nav/NavBar.astro` | 在 Logo 旁挂载时间进度 |
| `src/components/widgets/ProgressStats.astro` | 年积日 / 年度进度 / 今日进度 UI 与定时刷新 |
| `src/utils/data.ts` | `getPublishedBlogPosts`、`getBlogStats`、`getRecentBlogPosts` |
| `src/utils/blog-stats.js` | 可读单位、字数求和、日期间隔、中文数量格式化 |
| `src/utils/recent-post-date.js` | 上海时区的相对/绝对日期 |
| `src/utils/progress-stats.js` | 本地时区进度计算 |
| `plugins/remark-reading-time.ts` | 写入 `wordCount`，并在未指定时估算 `minutesRead` |
| `test/blog-stats.test.mjs` | 字数、日期间隔、中文格式化与缺值失败 |
| `test/recent-post-date.test.mjs` | 今天 / 30 天边界 / 未来日期 |
| `test/progress-stats.test.mjs` | 平年起点、闰日与日内分数进度 |

## 5. 验证

```bash
pnpm test:blog-stats
pnpm test:recent-post-date
pnpm test:progress-stats
pnpm check
pnpm build
```

浏览器至少验证：

- 首页副标题下统计与正文下 5 条时间线
- 草稿文章不进入首页统计和近期列表
- 导航 Logo 旁三项进度，刷新后数字会变
- Light / Dark，以及约 `1280px`、`768px`、`390px`
- 从其他页面经 ClientRouter 回到首页后，日期与进度仍只初始化一次

## 6. 后续修改入口

- 改字数或跨天规则时，同步 `blog-stats.js` 与 `test/blog-stats.test.mjs`。
- 改近期列表条数或日期文案时，同步 `getRecentBlogPosts()`、`recent-post-date.js` 与对应测试。
- 改进度含义或刷新频率时，同步 `progress-stats.js`、`ProgressStats.astro` 与对应测试。
- 首页统计和博客列表如果要共用同一套草稿策略，需要先改 `getPublishedBlogPosts()` 再核对两处页面。
